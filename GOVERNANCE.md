# Governance

This repository is an independently installable Orbit Grafana plugin maintained in the open. Governance describes project practice; it does not grant hosting-platform permissions or change branch rules.

Routine technical changes proceed through reviewed pull requests. Record an ADR under `docs/architecture/adr/` for public contract, plugin identity/type, compatibility, security, or dependency-boundary changes. Only authorized maintainers publish and sign plugin releases or change repository settings. Stable releases require hosted Grafana compatibility evidence, dependency review, signed artifacts, and provenance; local checks alone do not establish release readiness.
