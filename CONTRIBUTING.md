# Contributing

Contributions are welcome. Read the [package overview](README.md), [architecture](docs/architecture/overview.md), [operations](docs/operations/README.md), and [security](docs/security/overview.md) guides before changing public behavior. Preserve Grafana plugin compatibility and the Orbit Core → metrics capability → Prometheus exporter → Grafana layering.

Use the commands in [development](docs/development/README.md). Add focused coverage for changes, update documentation and `CHANGELOG.md`, and state which Grafana versions and checks were exercised. Keep credentials, personal data, local environments, caches, and build artifacts out of source control. Do not commit, publish, change GitHub settings, or sign plugin releases as part of local implementation work. Contributions are licensed under Apache-2.0.
